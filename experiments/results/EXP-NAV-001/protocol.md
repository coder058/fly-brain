# EXP-NAV-001 — navigation testbed boundary

Status: DEFERRED_HARDWARE.

Question: what minimum evidence would justify a navigation smoke test?
No drone, simulator, camera, IMU, or microphone is available on Ubuntu-1.
Prerequisites: named simulator, fixed scenario, deterministic seed, sensor
contract, safety boundary, train/test split, and a no-agent baseline.
The first run would be a protocol-only smoke with no claim of navigation skill.
A real run requires hardware or a reproducible simulator and a new frozen
experiment directory. This document does not authorize a drone deployment.
