# ROUTING-002 — fixed gain-envelope calibration

## Status

Protocol frozen before ROUTING-002 metrics. This is an instrument-resolution
experiment, not a routing or biological-function claim.

## Question

Is the incomplete block-preserving contrast in ROUTING-001 explained by the
reachable activity envelope at the fixed target rate, and which common
operating points are reachable across the three graph arms?

## Scope

- Biological structure: the same frozen MaleCNS v1.0 subgraph and labels as the
  repaired ROUTING-001 protocol.
- Arms: connectome_signed, degree_preserving, block_preserving.
- Same 500-node top-out-degree subgraph, same two selected superclass groups,
  same fixed local-ID inputs and probes, same signed weights, and same null
  constructors. Do not change ROUTING-001 artifacts.
- No task trials, no readout fitting, no routing margin, no test-set metric.
  Only non-input pool activity rate is measured.
- Seeds: exactly 0..11.
- Calibration currents: the same eight independent currents per seed as
  ROUTING-001; calibration currents are not task trials.

## Fixed gain grid

For every arm and seed, evaluate exactly nine logarithmically spaced gain
values generated by geomspace(0.05, 80.0, 9), including both endpoints.
The grid is fixed before seeing any curve. Gain normalization uses absolute
spectral radius, matching the repaired ROUTING-001 and existing MEM-002/003
rate-matching convention.

At each grid point record gain, synaptic scale, absolute/signed spectral
diagnostics, non-input pool spikes, denominator, and pool rate. The existing
instrument target 0.002 and relative tolerance 0.15 are reference values only;
they are not retuned here.

## Resolution rule

An arm/seed is TARGET_REACHABLE_ON_GRID if at least one fixed grid rate is
within 15% relative error of 0.002. Otherwise it is TARGET_NOT_REACHED_ON_GRID.
No grid point is selected for a later task from its measured rate in this
experiment. A later task operating point, if justified, must be pre-registered
as a new experiment and applied identically to all arms.

## Controls and interpretation

- Same graph nodes, edge count, weights, calibration currents, gains, and seeds
  make rate envelopes directly comparable.
- This resolves whether ROUTING-001 target-rate missingness is an instrument
  envelope problem. It does not repair or reinterpret ROUTING-001.
- A rate envelope difference is not evidence of a routing advantage; it may
  reflect signed dynamics, spectral normalization, or graph excitability.
- No novelty, biological, memory, or ML claim is allowed from ROUTING-002.

## Compute and failure policy

Planned workload is 3 arms x 12 seeds x 9 gains x 8 calibration trials x
32 steps = 82,944 sparse LIF steps, plus graph/null construction and spectral
diagnostics. This is an arithmetic workload estimate, not a measured runtime.
Run one process only. Write metadata and one immutable JSON checkpoint per seed;
never overwrite old ROUTING-001 or other results. Stop before execution if
sizing predicts more than approximately four hours, RAM pressure, disk
exhaustion, raw-data access, or derived-graph writes.

## Reproducibility

Record exact git HEAD, protocol/code SHA256, graph hashes, fixed gain grid,
selected labels/nodes, arm diagnostics, per-seed/per-arm/per-gain rates, and
target reachability. Raw and derived graph files remain read-only.
