# CIRCUIT-MINE-001 — structural circuit inventory

Status: preregistered before metrics

## Question

Does the frozen MaleCNS v1.0 graph contain higher-order structural concentrations
that justify a direct computational hypothesis, beyond treating the whole graph
as a generic reservoir?

## Scope

This is a read-only structural inventory, not a task benchmark and not evidence
of biological function. It uses the existing derived sparse archives and the
existing neuron annotation table. It does not read or write data/raw/ and does
not rebuild data/derived/graph/.

## Measurements fixed in advance

- node and directed-edge counts from graph_meta.json;
- in-degree and out-degree distribution summaries;
- strong and weak connected-component size summaries;
- directed reciprocal-edge count and reciprocal-pair count;
- per-node reciprocal degree;
- annotation composition of the largest strongly connected component;
- a ranked inspection list of the highest reciprocal-degree nodes, with
  annotations attached where available.

No threshold is chosen from an outcome. The ranked list is descriptive and is
not itself a candidate biological circuit.

## Candidate mechanism generated by this inventory

If a compact recurrent/reciprocal concentration is observed, the follow-up
question is whether recurrence can implement state retention or routing under a
task-specific, parameter- and compute-matched control. If no concentration is
observed, recurrence is downgraded and the queue moves to another mechanism
family.

## Controls and falsifiers for any follow-up

The follow-up must use a mechanism-matched null: degree-preserving rewiring,
weight permutation, and a parameter/compute-matched sparse recurrent baseline
where feasible. It must validate liveness with a synthetic positive control,
use independent train/test data, and survive independent seeds. A structural
concentration alone falsifies nothing and is not a discovery.

## Compute and stop rule

One CPU job loads the existing sparse graph and computes sparse graph
connectivity. No raw-data scan or graph rebuild is allowed. Record runtime and
peak memory after execution. Stop if the process approaches the host memory
limit or if an output would touch a protected data path.

## Output

research/circuit_mining_summary.json and a concise interpretation in
research/BREAKTHROUGH_CANDIDATES.md. The summary must distinguish measured
structure from proposed mechanism.
