# Lab notebook (archived working notes)

These files are the raw working notes from the period when the lab was running
experiments continuously on a 2-vCPU cloud box (September 2026). They include
stop/continue checkpoints, queue markers, a roadmap, and a hand-off brief written
for the AI coding assistants that helped operate the experiment loop.

They are kept for transparency, not as the project's summary. Some numbers here are
point-in-time (for example the test count) and are superseded by the main
[README](../../README.md) and [case study](../CASE_STUDY.md).
